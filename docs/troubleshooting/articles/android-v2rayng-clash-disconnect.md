# 安卓 v2rayNG 与 Clash Meta for Android 节点失效与后台断连排查

## 核心结论（Answer-First）

安卓端 v2rayNG 与 Clash Meta for Android 出现“亮屏可用、锁屏断连”或假死，多数源于手机厂商的后台冻结、电池优化限制，或 `VpnService` 被广告拦截类 App/另一款代理软件抢占。此外，Wi-Fi 与 5G 切换时的旧套接字悬空及系统“私人 DNS”冲突也会引发断流。关闭省电限制、锁定后台并按状态栏钥匙图标分流诊断即可根治。

## 故障现象

- **锁屏熄屏后断连**：手机熄屏放进口袋 3–10 分钟后，微信外链或海外消息不再推送；点亮屏幕发现顶部状态栏的“钥匙 / `VPN`”小图标彻底消失，或图标虽在但所有网页一直转圈。
- **开关秒回弹**：点击 v2rayNG 右下角启动按钮或 Clash Meta 启动卡片后，1 秒内自动弹回“已停止”，或底部一闪而过提示 VPN 授权失败。
- **跨网漫游假死（进出电梯/离家断流）**：在家里连 Wi-Fi 正常，走进电梯或出门自动切到 5G 流量后立刻断网，必须手动进 App 点一下断开再重连才能恢复。
- **部分应用漏代理**：Chrome 浏览器可以正常访问外部网页，但 Telegram、X（Twitter）或特定 AI 客户端一直显示 `Connecting...`，且代理日志里完全看不到该 App 的连接记录。

## 先做 3 个低风险检查

1. **看一眼顶部状态栏“钥匙 / VPN 图标”还在不在（核心分水岭）**：
   - **钥匙图标直接消失了**：100% 说明 `VpnService` 进程被安卓系统省电管家强杀了、内存不足（OOM）回收了、客户端自身崩溃了，或者被手机上另一个 VPN 类软件抢走了通道——重点做保活与互斥排查。
   - **钥匙图标稳稳挂着但没网**：说明客户端外壳还在运行，问题出在 Wi-Fi/5G 切换旧连接卡死、系统“私人 DNS”冲突、分应用代理漏选或远端节点自身超时——重点做网络栈与真连接排查。
2. **区分“真连接延迟”与假 Ping**：在 v2rayNG 点击右上角菜单选择 **测试全部配置真连接**（在 Clash Meta 点击策略组右下角闪电图标测速）；若返回 `150ms` 等正数说明节点健康，若全屏返回 `-1ms` 或 `Timeout` 则是节点或机场订阅侧故障。
3. **核查系统“私人 DNS（Private DNS）”**：进入系统 **设置 -> 网络与互联网（更多连接） -> 私人 DNS**。安卓 9+ 的私人 DNS 采用 `TLS over TCP 853 (DoT)`，若你填了境外加密 DNS 或国内过滤 DNS，在代理 TUN 接管瞬间极易与客户端内置 DNS 互锁，排查时请先改为 **关闭**（或默认的“自动”）。

## 国产主流安卓系统后台防杀与省电豁免路径对照表

国产定制 ROM 为了续航评分，往往叠加了“应用电池策略 + 自启动管理 + 锁屏清理 / 睡眠待机优化”三道枷锁，漏掉任何一处都可能在夜间或熄屏 10 分钟后断流：

| 手机系统品牌 | 应用耗电无限制路径 | 自启动与后台关联权限 | 系统隐藏的全局锁屏断网开关（极易漏查！） |
| :--- | :--- | :--- | :--- |
| **小米 / Redmi（澎湃 HyperOS / MIUI）** | 长按图标 -> 应用信息 -> 省电策略 -> 选择 **无限制** | 应用信息 -> 开启 **自启动**（HyperOS 位于后台启动权限） | 手机管家 -> 右上角齿轮 -> 省电与电池 -> 右上角齿轮 -> 将 **锁屏后断开数据** 设为从不，关闭睡眠模式断网 |
| **OPPO / 一加 / 真我（ColorOS）** | 长按图标 -> 应用详情 -> 耗电管理 -> 开启 **允许完全后台行为** 与允许后台运行 | 应用详情 -> 开启 **允许自启动** | 设置 -> 电池 -> 更多设置 -> **睡眠待机优化**（关闭它，否则夜间自动切断一切后台网络套接字） |
| **vivo / iQOO（OriginOS）** | 长按图标 -> 应用信息 -> 电池（耗电详情） -> 后台耗电管理 -> 选 **允许后台高耗电** | 权限管理 -> 权限 -> 自启动 -> 允许 v2rayNG / Clash Meta 自启 | 设置 -> 电池 -> 更多设置 -> 关闭 **睡眠模式** 下的限制后台数据选项 |
| **华为 / 荣耀（HarmonyOS / MagicOS）** | 设置 -> 应用和服务 -> 应用启动管理 -> 找到客户端**关闭“自动管理”**，在弹窗手动全勾 **允许自启动 / 允许关联启动 / 允许后台活动** | 同左弹窗三项全开 | 设置 -> 电池 -> 更多电池设置 -> 确保开启 **休眠时始终保持网络连接** |

## 分层原因排除

### 本地系统与网络

- **厂商墓碑机制与进程冻结**：现在许多系统即便不彻底杀死进程（所以钥匙图标还在！），也会用 cgroup Freezer 把后台 App 线程直接“冰冻”，导致 Xray / Mihomo 内核无法响应本地 TUN 网卡读写，亮屏几秒解冻后仍处于半死状态。
- **Wi-Fi 与 5G 蜂窝切换时的套接字悬空（Stale Socket）**：手机从家庭 Wi-Fi 切到运营商 5G 网络时，本地公网源 IP 瞬间变化。基于 TCP 的长连接在未收到 RST 前会经历漫长的重传超时；而未正确实现连接迁移或被运营商限制的 UDP/QUIC 节点也会往失效的旧网络句柄发包，造成长达半分钟的“假连无网”。
- **系统时间未自动同步**：备用机拔卡长期闲置后手动改过时间，会导致 VLESS/Trojan/VMess 全部握手失败。

### 客户端与核心配置

- **分应用代理（Per-App Proxy）黑白名单配反**：在 v2rayNG「设置 -> 分应用代理」中，勾选了“绕过模式（黑名单）”还是“代理模式（白名单）”很容易看混——若选了仅代理勾选应用却没勾浏览器，或者把 Android 系统底层组件如 `Google Play 服务` 漏在了外面，就会出现局部 App 彻底断联。
- **关闭了常驻通知权限导致前台服务降级**：Android 8.0+ 规定持有 `VpnService` 的客户端必须挂一条通知栏常驻消息维持 Foreground Service 优先级；许多用户觉得通知栏碍眼手动屏蔽了通知，导致系统名正言顺在锁屏后将其当作低优后台回收。
- **仍在使用早已停更的老旧安装包**：例如原版 `Clash for Android (CFA)` 早已归档停更，不认识 `VLESS Reality`、`Hysteria2` 或新版 `Mihomo` 语法；又或者从非官方应用商店下载了来路不明的篡改版客户端。

### DNS 与路由分流

- **Fake-IP 在移动网络切换时产生短时残留**：Clash Meta / FlClash 开启 `fake-ip` 且缺少微信、国内门户的 `fake-ip-filter` 时（详见 [Fake-IP 原理与 198.18.0.1 冲突修复](/troubleshooting/articles/fake-ip-explained-fix)），切网重启瞬间容易让国内 App 卡在连接中。
- **移动蜂窝网 IPv6 双栈干扰**：三大运营商 5G 普遍默认下发原生 IPv6，若手机端代理开启了 IPv6 路由接管但远端机场节点根本不支持 IPv6 出站，双栈应用优先尝试 `AAAA` 记录就会先卡顿超时再回退 IPv4。

### 远端订阅与节点

- **节点超售或设备数超限踢线**：电脑与手机同时挂着限制“最多 2 台设备在线”的低价套餐，或晚高峰中转入口过载，会导致手机后台长连接被服务端主动断开。

## 操作路径

### 适用平台说明

- **适用平台**：Android（涵盖原生 Pixel/三星 OneUI、小米 HyperOS/MIUI、OPPO ColorOS、vivo OriginOS、华为/荣耀系统上的 `v2rayNG`、`Clash Meta for Android (CMFA)`、`FlClash` 等客户端）。
- **不适用平台**：Windows、macOS、iOS/iPadOS、Linux、OpenWrt 均**不适用**本篇操作（iOS 由系统统一管理 `NetworkExtension` 50MB 内存上限而无安卓式自启动开关，桌面端与软路由请查阅对应平台排障文）。

### 具体排查与保活修复步骤

1. **步骤 1：按“钥匙图标状态”做第一轮精准分流**
   - **若锁屏后钥匙图标消失**：先对照上方厂商表格完成“无限制耗电 + 允许自启动 + 关闭睡眠断网”，再打开系统多任务卡片界面，下拉或长按客户端卡片点亮 **小锁图标**；同时在「应用信息 -> 通知管理」确保允许常驻通知。
   - **若点击启动按钮秒弹回，或用着用着钥匙图标被顶掉**：进入系统 **设置 -> VPN**，检查是否安装了本地去广告软件（如 AdGuard 本地 VPN 模式）、内网办公零信任软件（如飞连、EasyConnect）、游戏加速器或第二个代理 App。Android 全局只允许**唯一一把 VPN 钥匙**，必须关掉另一个占坑工具。

2. **步骤 2：优化客户端跨网切换（Wi-Fi <-> 5G）与 IPv6/DNS 兼容**
   - **关闭系统私人 DNS**：在系统连接设置中将「私人 DNS」设为 **关闭**，把 DNS 解析权完整交还给代理客户端核心的分流规则，消除切网时的 853 端口握手死锁。
   - **核对 IPv6 路由设置**：除非你明确确认机场节点支持原生 IPv6 转发，否则在 v2rayNG「设置 -> 启用 IPv6」建议保持**未勾选**（在 Clash Meta「设置 -> 网络 -> IPv6」保持**关闭**），强制代理隧道干净地走 IPv4，大幅减少 5G 切 Wi-Fi 时的双栈等待卡顿。
   - **核对分应用代理**：不确定为什么某个 App 不走代理时，先在客户端里暂时**关闭分应用代理**测试全局规则是否秒通；确认通畅后，再采用“绕过模式（Bypass）”仅勾选微信、支付宝、网银等纯国内高频 App 让其直连。

3. **步骤 3：通过 ADB 验证系统底层 Doze 白名单与被杀原因（进阶只读诊断）**

   如果你已经在手机设置里调成了“无限制”，锁屏半小时依然掉钥匙图标，可在电脑上通过 USB 调试用官方 `adb` 只读命令查明真相：

   - **适用 OS**：Windows / macOS / Linux 连接 Android 手机（手机开发者选项开启 USB 调试）
   - **目的**：核实客户端包名是否真正写入了 Android 底层 `deviceidle` 免休眠白名单，并查询系统最近一次杀死该进程的精确原因码（Android 11+ 支持 `getHistoricalProcessExitReasons`）。
   - **风险等级**：低（纯只读 `dumpsys` 查询，不修改任何系统分区或权限）。

   ```bash
   # 1. 检查包名是否已在 Doze 电池优化白名单中
   adb shell dumpsys deviceidle whitelist | grep -iE "v2ray|clash|meta"
   # 2. 查看系统记录的最近退出/查杀原因（以 v2rayNG 包名为例）
   adb shell dumpsys activity exit-info com.v2ray.ang | head -n 25
   ```

   - **预期输出解读**：
     - 第一条命令应输出类似 `user,com.v2ray.ang,102xx` 或 `user,com.github.kr328.clash.foss,...`；若输出为空，说明厂商 UI 开关未同步到底层白名单，需去系统自带「手机管家」二次放行。
     - 第二条命令若看到 `reason=REASON_EXCESSIVE_RESOURCE_USAGE` 或 `REASON_OTHER (Cleaner)`，实锤为厂商省电引擎强杀；若看到 `reason=REASON_LOW_MEMORY`，说明后台同时打开了大型手游触发物理内存不足（OOM），此时精简配置规则集（如改用轻量 `.mrs` 规则替代庞大 `.dat` 库）能显著降低常驻内存避免被杀。

4. **步骤 4：切网与熄屏实测验收**
   - 连接一个真连接延迟正常的 TCP 承载节点（如 VLESS-TCP 或 Trojan），手动关闭手机 Wi-Fi 切换到 5G 数据观察网页能否在 3 秒内继续刷新；随后锁屏静置 15 分钟，亮屏后直接打开浏览器验证是否秒开。

## 什么结果算修复

- 手机锁屏待机 15–30 分钟甚至夜间待机后，状态栏 VPN 钥匙图标稳固在位，海外即时通讯消息能实时弹窗推送，亮屏即用无需手动重连。
- 从室内 Wi-Fi 走到室外 5G 环境时，连接能在 2–5 秒内自动平滑恢复，不再长时间假死转圈。
- 客户端真连接测速持续返回稳定毫秒值，所有目标 App 按预期分流联网。

## 若仍失败怎么办

- **升级或平滑更换仍在维护的轻量客户端**：若你仍在用停更数年的原版 CFA，或某款客户端在你的手机 ROM 上内存占用过高频繁 OOM，建议参考 [客户端软件矩阵](/clients/) 迁移至持续维护的新版 `v2rayNG`、`FlClash`（基于 Mihomo 且多端统一）或官方 `sing-box for Android (SFA)`（安全提醒：请认准官方渠道，切勿在应用商店下载带广告或窃密嫌疑的李鬼仿冒 NekoBox）。
- **区分本地杀后台与节点全线瘫痪**：如果钥匙图标一直都在，但切成任何网络、换了多个客户端测真连接都是 `-1` 超时，请转入 [所有节点同时超时排查](/troubleshooting/articles/nodes-all-timeout) 或 [连上节点但打不开网页排查](/troubleshooting/articles/connected-no-internet)。
- 进一步了解移动端系统级沙盒与内存边界，可阅读 [手机 VPN 保活机制详解](/vpn/mobile/) 与 [安卓 VPN 与 VpnService 指南](/vpn/android/)。

## 高风险操作与回滚提示

- **谨慎开启系统级“始终开启的 VPN（Always-on VPN）”叠加“阻止无 VPN 的连接”**：在 Android「设置 -> VPN -> 齿轮设置」中一旦同时打开这两项，只要代理客户端因配置错误崩溃或机场节点欠费停机，系统内核会**物理级阻断整台手机的一切直连网络**（连微信、12306、扫码支付和机场官网续费页都打不开，新手常误以为手机基带坏了！）。**回滚方法**：进入系统 `设置 -> 网络与互联网 -> VPN`，点击对应客户端右侧齿轮图标，关闭 **阻止无 VPN 的连接** 与 **始终开启的 VPN**，手机直连网络即刻恢复。
- **关闭私人 DNS 与分应用代理的回滚**：若排障后希望恢复原有的去广告私人 DNS 或分应用绕过列表，回到系统「私人 DNS」重新选回原保存主机名，或在客户端重新开启已保存的分应用勾选列表即可。
- **切勿关闭手机安全中心的病毒查杀或刷入来路不明的保活 Root 模块**：正规安卓保活只需设置上述官方系统电池与后台开关，完全不需要 Root 手机或停用系统防护。

## 常见问题

### 为什么手机亮屏时一切正常，锁屏几分钟后节点就彻底断网必须重新开关？

国产安卓定制系统（如 HyperOS/MIUI、ColorOS、HarmonyOS、OriginOS）在锁屏后会主动触发 Doze 深度休眠并冻结后台网络套接字，甚至直接回收 VpnService 进程。必须在系统的应用耗电管理中设为“无限制/允许后台高耗电”，并在多任务卡片上锁定该应用。

### v2rayNG 显示已连接，真连接测试也通，但部分 App 仍然连不上怎么办？

先检查是否开启了“分应用代理（Per-app proxy）”并误把目标 App 排除在外或纳入了黑名单；其次检查系统是否开启了“私人 DNS（Private DNS）”加密 DNS，部分环境下私人 DNS 会与客户端本地 DNS 拦截产生冲突。

### 提示“另一个 VPN 正在运行”或开关刚打开又自动弹回关闭是怎么回事？

Android 系统底层同一时间只允许一个应用持有 VpnService 隧道权限。广告拦截工具（如本地过滤类 App）、企业安全客户端或另一个同时开启的代理软件都会抢占该通道，导致当前客户端刚建立连接就被系统强制断开。

### 走出家门从 Wi-Fi 切换到 5G 移动网络时，为什么钥匙图标还在却打不开任何网页？

这是跨网卡切换引起的悬空连接（Stale Socket）现象。手机出口从宽带切换为蜂窝基站后源 IP 已变更，若旧的 UDP/QUIC 隧道或系统“私人 DNS（DoT）”长连接未能即时感知断开重建，数据包仍发往失效套接字就会卡死。关闭冲突的系统私人 DNS、启用客户端网络变更自动重连或切换 TCP 协议节点即可显著改善。
