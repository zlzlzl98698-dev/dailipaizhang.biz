# 套餐到期、流量耗尽与客户端旧配置过时的快速区分指南

## 核心结论（Answer-First）

节点突然全线断联，既可能是套餐到期、高倍率耗尽流量，也可能是账户正常但客户端缓存的旧配置已过时。快速区分只需两步：一查订阅响应头 `subscription-userinfo` 与客户端流量条是否出现“已到期/流量耗尽”提示；二登官网后台核对真实余量与重置日期。若后台余量充足且刷新订阅后节点列表变化，即为旧配置过时。

## 故障现象

三种场景表面上都表现为“所有节点无法上网或超时”，但细节特征截然不同：

- **套餐到期或流量耗尽的特征**：
  - 客户端订阅卡片进度条变成红色满格，或到期日显示已过期。
  - 触发“更新订阅”后，原本的地区节点全部消失，取而代之的只有 1–2 条名为 `剩余流量：0.00 GB`、`套餐已到期` 或 `请前往官网续费` 的提示伪节点；或者更新订阅直接报 `403/401`（或返回 `200` 空白）。
  - 如果此前一直没点过更新订阅，旧节点还在列表里，但连接任何节点都会在握手阶段被远端立即重置（`EOF` / `connection reset by peer`）或全超时。
- **客户端旧配置过时的特征**：
  - 官网后台显示套餐依然在有效期内，且剩余流量充沛。
  - 本地一直没有开启自动更新，或者一直勾选着早期的旧本地配置文件（比如手动导入过一个静态 `.yaml` 文件而非托管订阅链接）。
  - 客户端日志中核心仍在尝试连接已经停用或迁移端口的旧 IP，或者报协议参数不匹配错误。

## 先做 3 个低风险检查

1. **查看客户端订阅卡片下的流量与到期数字**：Clash Verge Rev、Shadowrocket 等客户端在订阅条目下方会直接渲染来自响应头的流量统计（已用 / 总量 / 到期时间）。先看这里的数字是否已经停留在很久以前的刷新时间，或直接显示耗尽。
2. **登录服务商网页后台进行真实对账**：不要只看客户端本地缓存，直接打开官网面板核实三项指标：**到期日期、本月剩余流量、流量重置倒计时**，以及**近期公告**是否要求“所有用户重新更新订阅”。
3. **点击一次“更新订阅”观察节点列表的变化**：如果是旧配置过时，刷新后会看到节点端口、域名或名称发生变化并立刻恢复可用；如果刷新后节点变成了提示文字或报错，则是账户状态或订阅链接本身失效。

## 分层原因排除

### 本地系统与网络

- **设备长期睡眠后本地时间戳或缓存未刷新**：电脑长时间未开关机或手动导入过本地文件副本，导致客户端一直加载本地磁盘里的过期文件，即使后台其实发过通知也未能同步。
- **多端并发超限触发风控**：家里电脑、手机、平板、路由器同时挂着同一个订阅账号，如果套餐严格限制同时在线设备数或 IP 数，部分设备会被后端临时踢下线，误以为是流量耗尽。

### 客户端与核心配置

- **导入方式选错（本地静态文件 vs 在线订阅 URL）**：不少新手是从官网点击“下载配置文件”后拖进客户端的。这种本地导入方式**不会自动同步后续服务端节点变动**，一旦机场更换中转 IP，本地静态配置就会永久过时。
- **覆写规则或锁定了已被删掉的旧节点名**：在 Clash Verge Rev 里给某个策略组固定选定了 `香港 01-旧专线`，而服务商更新订阅后改名为 `香港 IEPL-01`，旧策略缓存依然引用不存在或已停用的节点导致报错。

### DNS 与路由分流

- **订阅更新时 DNS/代理未通导致“静默更新失败”**：客户端看似开启了“定时自动更新”，但每次都在错误网络状态下悄然失败，结果用户以为“昨天才自动更新过”，实际用的仍是三个月前的旧配置。

### 远端订阅与节点

- **高倍率节点导致的“隐性流量耗尽”**：许多机场针对高速专线（如 IEPL/IPLC 或原生解锁节点）设置了 `2x`、`3x` 甚至 `5x` 的流量倍率。例如实际下载了 20GB 文件，在 `5x` 节点上会被直接扣除 100GB 配额，让用户误以为“才刚买没两天怎么就断网了”。
- **后台迁移面板/重置了全员节点端口或域名**：服务商升级服务端端口策略、应对线路波动更换全套中转入口，老配置全部失效。
- **不限时流量包 vs 周期月付包规则误解**：误以为买的是永久不限时包，实则是按月清零或有效期 30 天的套餐，到期日一过服务立即停止。

## 操作路径

### 步骤 1：用命令行读取订阅响应头 `subscription-userinfo`（快速验真）

在本地使用脱敏占位 URL `https://sub.example.com/api/v1/client/subscribe?token=REDACTED` 请求一次响应头，即可在不猜测的情况下读取服务端返回的精确字节数（实际操作时自行替换为真实地址，注意勿对外泄漏完整 Token）。

**命令 A：读取 `subscription-userinfo` 流量与到期时间戳（Windows PowerShell）**

- **适用 OS**：Windows 10 / Windows 11
- **目的**：直接从订阅响应头提取上传（`upload`）、下载（`download`）、总流量（`total`）和到期时间戳（`expire`）并换算成 GB 与北京时间。
- **风险等级**：低风险（只读 HTTPS 请求）。
- **预期输出解读**：如果 `UsedGB >= TotalGB` 说明流量确实耗尽；如果 `ExpireDate` 早于当前日期说明套餐已到期；如果响应头直接报错 `401/404` 或未包含该字段但面板正常，请登录后台重新复制新订阅链接。

```powershell
$u = "https://sub.example.com/api/v1/client/subscribe?token=REDACTED"
$resp = Invoke-WebRequest -Uri $u -Headers @{"User-Agent"="ClashVerge/2.0.0"} -UseBasicParsing
$info = $resp.Headers["subscription-userinfo"]
Write-Output "Raw Header: $info"
if ($info -match "upload=(\d+);\s*download=(\d+);\s*total=(\d+)(?:;\s*expire=(\d+))?") {
  $used = ([double]$Matches[1] + [double]$Matches[2]) / 1GB
  $total = [double]$Matches[3] / 1GB
  $exp = if ($Matches[4]) { ([DateTimeOffset]::FromUnixTimeSeconds([long]$Matches[4])).ToLocalTime().ToString("yyyy-MM-dd HH:mm:ss") } else { "不限时/未返回" }
  [PSCustomObject]@{ UsedGB = [math]::Round($used,2); TotalGB = [math]::Round($total,2); ExpireDate = $exp }
}
```

**命令 B：提取 `subscription-userinfo` 并换算到期时间（macOS / Linux / OpenWrt）**

- **适用 OS**：macOS、Linux、OpenWrt（SSH 终端）
- **目的**：只打印状态码与 `subscription-userinfo` 响应头，快速核对账户余量与过期时间。
- **风险等级**：低风险（只读 HEAD/GET 请求）。
- **预期输出解读**：重点查看 `upload` + `download` 是否已逼近或等于 `total`（单位为字节，除以 `1073741824` 即为 GB），以及 `expire` 的 Unix 时间戳是否已过去。

```bash
curl -I -sS -A "ClashVerge/2.0.0" \
  "https://sub.example.com/api/v1/client/subscribe?token=REDACTED" \
  | grep -iE "^(http/|subscription-userinfo:)"
```

> **iOS / Android 说明**：Shadowrocket 和 Clash Meta for Android 均会直接在“订阅/配置”首页的订阅名称下方自动解析并显示 `已用 / 总量` 和 `过期时间`。打开客户端先看一眼该行日期与百分比即可，不必运行命令行。

### 步骤 2：根据对账结果分流处理

- **情况一：确认流量耗尽或套餐已到期**
  1. 登录后台核对“下一次流量重置日期”，若距离重置日较久，可选择续费、购买流量重置包或启用备用机场。
  2. 检查近期客户端“连接历史/流量消耗”，排除后台大流量应用（如网盘同步、系统更新、BT 下载）在高倍率节点下偷跑流量。
- **情况二：后台有余量且未到期，确认属于“旧配置过时”**
  1. **Windows / macOS / Linux（Clash Verge Rev / v2rayN）**：不要继续使用之前本地拖入的静态 `.yaml` 文件。前往官网后台复制**在线订阅链接**，在客户端重新导入为“远程订阅（Remote Profile）”，并点击激活选中新配置。
  2. **iOS / Android**：长按或进入当前订阅设置，如果之前启用了“不更新”或旧 URL 已更换，从后台重新“一键导入”或粘贴最新在线订阅地址更新。
  3. **OpenWrt（PassWall / OpenClash）**：进入路由器的订阅管理页面，勾选“更新订阅”，更新完成后务必点击一次“保存并应用”重启内核进程使新节点表生效。

### 步骤 3：预防下次误判与高倍率消耗优化

1. 在客户端启用合理的订阅更新周期（如每次启动更新或每 24 小时自动更新一次），保证节点端口调整后能及时同步。
2. 认真区分节点名称里的倍率标识（例如 `0.5x`、`1x`、`2x`、`5x`）：日常刷视频、下载大文件优先使用 `1x` 或低倍率节点，把高倍率稀缺节点留给必须使用特定解锁的业务。

## 什么结果算修复

- 客户端内显示的“已用 / 剩余流量”和“到期日期”与服务商网页后台完全一致。
- 若为旧配置过时：重新导入并激活最新在线订阅后，新节点列表刷新生效，连接测速恢复正常延迟并能顺畅打开网页。
- 若为流量耗尽：处理流量重置或切换至有效备用套餐并刷新订阅后，伪提示节点消失、真实地区节点恢复可用。

## 若仍失败怎么办

1. **如果更新订阅时遇到 401/403/404 或返回空白**：按对应状态码排查，查看 [更新订阅失败：401/403/404/503 与被重定向排查](/troubleshooting/articles/sub-http-401-403-404-503) 或 [HTTP 200 返回空白订阅排查](/troubleshooting/articles/sub-http-200-empty)。
2. **如果确认服务商官网也已打不开、并非个人到期问题**：对照 [机场跑路识别与失联止损](/security/shutdown/) 检查服务商异常信号，并及时转移到 [服务失联替代方案](/security/alternatives/)。
3. **想系统了解倍率扣费计算规则**：阅读 [线路倍率计费与流量异常消耗排查](/routes/multipliers/) 与 [为何客户端测速与实际下载体感差异大及倍率计算](/troubleshooting/articles/bandwidth-multiplier-speedtest-diff)。

## 高风险操作与回滚提示

- **严禁关闭杀毒软件或轻信“无限免费重置流量”的第三方破解脚本**：流量额度与到期校验全部在远端服务端实时记账，任何声称能本地破解流量上限的工具均属于木马风险。
- **严禁在核对余额时把含 Token 的完整订阅链接发给他人代查**：他人只需拿到你的链接即可刷光你的剩余流量，请始终用脱敏占位方式自己运行查询或直接登录官网后台核对。
- **删除旧配置与重新导入前的备份回滚**：在客户端删除或覆盖旧配置文件前（特别是自己花费精力编写过自定义分流规则的配置文件），先右键将其导出或复制一份 `.yaml` 备份到桌面；若新导入配置不习惯或有规则缺失，直接重新导入备份文件并恢复自定义规则段即可完全回滚。

## 常见问题

### 为什么我才买了 100GB 流量没几天，下载没多少东西就提示流量耗尽了？

常见原因有两个：一是部分专线节点存在 2x、3x 甚至 5x 的高倍率计费，实际消耗 20GB 在 5 倍率节点上就会扣除 100GB 套餐额度；二是后台有应用（如云盘同步、Windows 更新或视频预加载）在全局代理下持续跑满流量。

### 官网后台明明显示还有 80GB 流量且没到期，为什么客户端就是连不上或节点全红？

这属于典型的“客户端旧配置过时”。机场可能在后台更换了中转服务器 IP、变更了入站端口或要求用户更新订阅以切换新协议，而你本地仍在使用数周前缓存的旧 YAML/节点列表，必须重新更新订阅并激活新配置。

### 为什么更新完订阅后，节点列表里只剩下“已到期”或“官网网址”两条假节点？

这是机场面板的标准提示机制。当账户到期、流量用光或订阅被吊销时，服务端不再下发真实代理节点，而是将状态文字伪装成一条提示节点返回给客户端，提醒用户登录后台处理。
