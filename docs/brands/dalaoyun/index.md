## 二、同质盘怎么做 A/B 验证

由于资料没有任何实测，唯一可行的办法是自己跑一遍对照，并把成本压到最低：

1. **只买最短周期**：7 折适用于季付及以上，若面板有月付就优先月付；没有月付时，宁可选季付，不选年付。
2. **同一天、同一网络、同一工具**：用同一台电脑、同一个测速方式，在晚间 20 点到 23 点各跑一次，记录延迟与速度，避免用白天的结果比晚上的结果。
3. **只比三项**：晚间稳定性、你实际需要的地区是否有节点、你的客户端能否正常导入。
4. **设止损线**：任何一家出现连续失联或客服无响应，立即停止，不再追加。
5. **别叠加囤货**：五家都买一遍意味着五笔沉没成本，先买一家，不满意再换。
