## 一、2026-07-20/21 珠海联通 9Gbps 实测深度解析

不同于只测吞吐的常规表格，灵动云的历史记录保留了一次覆盖 **60 节点测速与 60 节点解锁**的测试结论摘要（测试时间 `2026-07-20/21`，测试后端 `珠海联通 9Gbps`）：

1. **吞吐与延迟表现（20–80MB/s 够用级，HTTPS 延迟偏高）**：
   - 在 9Gbps 大带宽测试端下，20–80MB/s 属于日常 4K 串流与办公够用水平，但并未跑出百兆字节以上的高并发峰值；同时测试记录明确指出 **HTTPS 延迟偏高**，意味着首包建连或网页高频短连接加载时的体感可能不如低 RTT 专线干脆（参见[低延迟节点与 TLS/HTTPS 延迟区别](/routes/low-latency/)）。
2. **核心优势：OpenAI 各地区基本全解锁**：
   - 在 60 解锁样本中，灵动云在 OpenAI 访问上表现出众，各主要地区节点均能顺利触发解锁，这对依赖 ChatGPT / OpenAI API 协作的用户具有实质吸引力。
3. **四大明确短板与失效节点**：
   - **美国 01 整节点失败**：基础常用节点直接失效，证明即便在 2026 年 7 月测得较好 AI 解锁，单节点可用性依然有波动。
   - **TikTok 多节点失败**：若你的核心需求是跨境电商 TikTok 运营或直播推流，该历史测试结果明显不利。
   - **新加坡 / 台湾节点 YouTube 送中**：与光速云 70 节点测试类似，新、台节点出现 YouTube 送中（定位回 CN）现象，影响免广告与区属推荐。
   - **台湾落地识别偏欧（ES）**：测试观察到台湾节点在 Netflix 与 Disney+ 上被识别为 **`ES`（西班牙）**，说明其台湾出口 IP 可能使用了欧洲广播段或数据库未更新的跨区 IP，无法当作原生台区流媒体节点使用。
