关键发现：**标准与进阶两档，半年付的月均价比年付更低**。如果你选年付，不仅多押了半年的风险，还多花了钱。只有高级档的年付才真正比半年付便宜，极限档两者几乎相同。

整体看折扣也很浅：标准年付相对月付仅约 90%，进阶约 95%，高级约 92%，极限约 96%。对比[浪网](/brands/langwang/)和[灵动云](/brands/lingdong/)的 85% 年付，EdgeNova 的长周期优惠力度明显更弱，没有理由为了折扣而冒险付长周期。

另有限时月付 ¥15/72G 与限时年付 ¥108/45G，单价约 ¥0.20 到 ¥0.21/GB，与标准档（约 ¥0.208/GB）几乎一致，说明所谓“限时”并没有明显更便宜。

## 二、多线路自动分配：资料没说清的地方

“多线路自动分配”可能意味着系统根据负载把你分配到不同线路。这一点资料没有解释：

- 是否可以手动指定节点或线路？
- 自动分配的依据是什么？
- 对需要固定出口 IP 的场景（例如某些账号风控）是否适用？

这些都需要向客服确认。对于需要稳定出口的用户，自动分配可能是个风险点，但**这只是推理，资料没有证实**。
