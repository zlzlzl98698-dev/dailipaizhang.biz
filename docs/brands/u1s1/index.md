# U1S1 评测：2000Mbps 宣称核查、1TB 包冲突与 22:33 晚高峰实测

**U1S1（u1s1）** 是 **2025 年上线**的新兴 IPLC 专线机场（套餐命名风格颇具辨识度，如“就是好用包”“普通人真够了包”）。与许多仅停留在白天的实测截图不同，U1S1 的 `2026-08-11` 截图恰巧跑在 **`22:33:29 (CST)` 夜间高负载窗口**，让我们得以观察其在真实夜间压力下的速度与延迟分布；同时，它也存在 **1000GB 一次性包在正文与表格之间脱节**的数据冲突。

## 一、宣传口径核查与套餐表冲突

1. **“2000Mbps 带宽与晚高峰不限速”属性界定**：此类表述属于**品牌资料单方宣称（`vendor`）**，仅说明其标称端口上限，不等于任意地区用户在单线程下都能跑满 2Gbps。
2. **1000GB 一次性流量包冲突**：
   - 介绍正文说“20 元 120GB 的套餐之外还有 1000GB 的一次性大流量包”；
   - 但同一条目上面的 5 行套餐表格里，只列出了 `就是好用包（¥96/年 60GB/月）` 和 4 档月付（¥20/120G、¥40/300G、¥100/700G、¥180/1500G），**并没有 1000GB 一次性包的任何价格与条目**。
3. **优惠信息有限**：公开优惠码为 `akaka`，未标注具体折扣率，且介绍正文也坦承“官方公开的优惠信息也比较有限”。

## 二、2026-08-11 22:33 晚间实测截图深度解读

![U1S1 2026-08-11 晚间节点测速截图，展示 65 个 Shadowsocks 节点的夜间延迟与速度。](/images/speedtests/u1s1-20260811.png)

> **图注（u1s1-20260811.png）**：测试时间 `2026-08-11 22:33:29 (CST)`，测试工具 `MAI-TEST-BOT 2.0.0-dev`，后端 `珠海联通 5Gbps(4.6.4)`，32 线程，Ping 5 次，消耗流量 27.7GB，协议 **`Shadowsocks`**，共 65 行（前 3 行为剩余流量 9851.8GB/到期提醒信息行）。
> - **港/新晚间峰值突出**：`香港专线 02–20` 平均速度普遍在 **`93–106.84MB/s`**（RTT 多数 15–20ms，仅香港专线16 跳到 92ms、香港专线20 HTTP 延迟高达 3561ms）；`新加坡 02–10` 平均在 **`99.00–107.52MB/s`**（但 `新加坡 01` 仅 `17.35MB/s`）。
> - **日本与美国明显分化**：`日本 01–10` 吞吐虽有 `80–110MB/s`，但**延迟 RTT 普遍在 `152–200ms`**（日本08 甚至达 `955ms`），显著高于常见日本专线延迟；`美国 01–10` 则呈现剧烈两极分化，其中 7 个节点平均仅 `5.37–10.52MB/s`，仅 `美国02`（67.63MB）、`美国07`（50.52MB）、`美国10`（31.52MB）相对较高。
> - **台湾与欧亚冷门节点**：台湾 01/02/04 约 `88–100MB/s`（台湾03 降为 `30.24MB/s`）；土耳其/法国/英国/越南多在 `4.96–26.44MB/s`，第 64 行某美国/英国节点仅 `61.34KB/s`。
> - **局限**：UDP 类型全部为 `Unknown`，无独立 AI/流媒体解锁截图，且品牌 2025 年上线至今运营周期仍短。
