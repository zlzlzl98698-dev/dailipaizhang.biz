- **核心资料冲突（共 3 处）**：
  1. **轻量版月流量冲突**：《光速云品牌信息.txt》顶部摘要写“年付折合约 8 元/月，59GB”，但同文件套餐详情段落与《32家机场品牌清单.txt》均写为“轻量版 ¥99/年，69GB/月”。
