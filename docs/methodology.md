# 测速与数据证据分级方法论（Methodology）

> **核心结论（Answer-First）**：为了杜绝把厂商宣传稿改写成“本站实测”，**代理排障（dailipaizhang.biz）** 对全站所有品牌参数、测速结果、解锁情况与拓扑示意执行**六级证据分级制度（`measured` / `vendor` / `third_party` / `historical` / `unknown` / `example`）**。同时严格界定 **`2026-08-11` 节点测速截图批次**、品牌资料表格（如 `2026-10-19`）与补充测试记录的边界——**保留原始异常（含 0B 与超时），绝不美化删减，不做无控制变量的跨品牌速度榜**。

## 一、六级数据证据分类体系

在品牌数据库、证据面板及所有评测页面中，每项关键数据都绑定对应的证据级别标识：

| 证据级别 | 中文定义 | 典型来源与采纳标准 | 禁止越界行为 |
| :--- | :--- | :--- | :--- |
| **`measured`** | **实测记录（带时间与工具约束）** | 站内保存的只读原始测速或流媒体测试截图（如 `2026-08-11` 批次、灵动云 `2026-07-20/21` 或光速云 `2026-08-19` Miaoko 截图），需明确标注测试时间、工具、后端与局限 | 禁止把单次截图外推成“全年稳定”或跨工具直接排第几名 |
| **`vendor`** | **服务商 / 品牌资料宣称** | 来自品牌方公开套餐表、介绍文案与官网参数（如开业年份、套餐价格/流量、协议声明、自称解锁列表及 `2026-10-19` 非晚高峰资料表格） | **严禁将 `vendor` 资料改写为“本站实测”** |
| **`third_party`** | **第三方公开评测或社区反馈** | 来自独立第三方工具或外部公开评测渠道记录（如外部测试报告、客户端开源项目说明），引用时注明出处范围 | 需与站内保留的原始实测截图区分，避免混算均值 |
| **`historical`** | **历史归档记录** | 较早时间采集但尚未完成最新复核的数据（如标记为 `2026-08-09` 的历史资料记录或早期截图），用于体现历史状态演变 | **严禁隐瞒历史属性当作当前最新现行资费或在线状态** |
| **`unknown`** | **未核实 / 暂无记录** | 资料包中未提及、官网无法访问或暂缺可靠来源的字段（如未核实的官网 URL、未明协议、暂缺客户端开源仓库完整地址） | **严禁靠猜补值**，页面统一明确显示“待核实 / 尚未核实 / 暂无可复核记录” |
| **`example`** | **概念或演示示例** | 仅用于解释网络原理的示意图（如直连/中转/专线概念拓扑图）或教程配置示例片段 | **必须显著标明“概念示意/非特定品牌物理拓扑”**，严禁进入品牌真实评测打分与 Schema |

## 二、重点实测批次边界：`2026-08-11` 16 机场测速截图包

本站归档了来源于 `16个机场测速图_2026-08-11_实测版.zip` 的 16 张只读原始 PNG 截图（全部尺寸为 `1122 × 1402 px`，统一存放在受控素材目录并附带清单索引）。使用这批数据时，必须遵守以下边界规则：

### 1. 可以确认的内容
- 每张图展示的测试时间均在 **2026-08-11（CST / UTC+8）**，但具体测试时刻分布于当天凌晨、白天至晚间（例如最早至 00:21，最晚至 22:46），**并非同一并发时刻完成**。
- 测试工具与接口并不完全一致：
  - 其中 14 张显示 **`MAI-TEST-BOT 2.0.0-dev`**（珠海联通 5Gbps 后端、32 线程、Ping 5 次，图中展示协议为 **Shadowsocks**）。
  - 另外 2 张（**宇宙云** 与 **快狸**）使用了另一套测试界面（**主端 4.3.3（696）/ 喵速 4.7.0（A11-32）**，珠海联通 9Gbps 后端、32 线程，图中展示协议为 **VLESS**）。
- 原始截图中如实包含了 **0B 节点、KB 级速度、高延迟异常、UDP `Unknown` / `FullCone` / `RestrictedCone`** 等真实结果——站点规范要求**绝不为了美化结论而隐藏 0B 或失败节点**。

### 2. 需要特别标注的批次例外与补充记录
- **可信云日期复核标注**：可信云图片底部显示 `15:32:35 CST`，但完整日历日期在图片裁剪边缘未能完全显露，按压缩包批次暂记为 `2026-08-11` 并保持 `review-required` 复核注记。
- **不在 31 品牌主名单的图像（快狸）**：`kuaili-20260811.png` 虽在原始测速包中，但因不在本期 31 家独立品牌资料清单内，作为待补充证据单独存档记录，不强行编造套餐与链接。
- **其他补充批次与资料文件**：部分品牌另保存有 `2026-07-18`（无忧链接 `wuyou-1.jpg` / `wuyou-2.jpg`）、`2026-07-19`（微风相关实测记录）、`2026-08-19`（光速云 5 张 Miaoko 三网测速与流媒体截图，包含 VLESS/AnyTLS 与部分地区的 YouTube 送中记录）以及 `2026-10-19` 品牌资料自带的非晚高峰测速表格。不同批次之间因为时间、后端和工具各异，**禁止混算平均值**。

### 3. 这批测速截图“不能证明”的五件事
1. **不能证明长期稳定**：单日某一时间点的截图无法代表全年各时段或晚高峰持久体验。
2. **不能直接生成横向排名**：测试时间跨度超过 22 小时，且存在两套不同测速前端与两种不同协议，横向排“第几快”在统计学上不成立。
3. **不能证明 AI 与流媒体解锁**：纯速度图不测试 Netflix、ChatGPT、Claude 等服务可用性（除非有独立的流媒体解锁检测图佐证，否则标注未实测）。
4. **不能反推物理线路（IEPL / IPLC / 原生 IP）**：测速图只反映吞吐与延迟表现，无法鉴定底层是否真实走企业内网专线。
5. **不能担保运营安全**：节点通畅不代表没有跑路、限速或退款纠纷风险。

## 三、原始资料冲突处理原则

在审计原始多份品牌数据时，若出现自相矛盾的数值（例如光速云轻量版在摘要写 59GB 而套餐表写 69GB、同一品牌在总表与详表出现不同优惠码、或年付折算价与月付入门价口径不一致），本站一律遵循**“不擅自猜对错，双口径并列披露并记入冲突记录”**的原则，确保读者在做决策前看到全部已知事实与不确定性。

## 四、常见问题

### 本站为什么把数据严格区分为 measured、vendor、third_party 等六个级别，而不直接写成一个总结论？
把商家自述宣传、历史旧记录和实时测量混写在一起是网络评测的最大失真来源。分级标注能让用户一眼分清“这是厂商自己说的”还是“某年某月某日某工具实际截到的”。

### 2026-08-11 批次的 16 张测速截图能证明哪些品牌的晚高峰长期稳定吗？
不能。它仅是特定时间点和测试环境下的一次切片证据，存在时间不统一、后端不同、含 0B 异常等多种变量，只能作为参考切片而非长期保证。

### 如果某个品牌完全没有可复核的测速或解锁记录，页面上会怎么显示？
页面会如实展示“暂无可复核的测速/解锁记录”，并注明缺口字段（`unknown`），绝不会使用占位数字假冒真实测评。
