## 一、评测方法论与数据可信度分级标准

在阅读各品牌具体报告前，建议读者先理解本站采用的 **六级证据分层框架**。代理行业存在大量的夸大宣传与信息不对称，唯有穿透文案表象，方能把握服务的真实可靠性：

1. **已实测验证 (measured)**：具备确切时间戳的第三方测速截图（如 2026-08-11 实测、2026-08-19 Miaoko 报告），记录了节点单线程/多线程吞吐、Ping 延迟、丢包率、0B 异常节点及流媒体/AI 实际解锁状态。
2. **历史测试归档 (historical)**：记录于早期归档档案中的测速数据（如 2026-07-18 至 2026-08-09 期间实测）。该部分数据具有重要趋势参考价值，但不能直接代表当前时刻的实时工况。
3. **商家官方宣称 (vendor)**：来自品牌方对外公告、官网套餐介绍及推广物料的声明（如宣称全 IEPL 专线、独享 2.5Gbps 带宽、7×24 技术客服等）。此类数据未经第三方中立复测，在报告中一律注明为商家声称。
4. **存在资料冲突 (conflicted)**：在不同宣传文件、价格表或测速面板中出现前后矛盾的数据。典型案例如光速云轻量版年付套餐在摘要中记录为 59GB/月而在明细中记录为 69GB/月；云界线总表与详表标注不同优惠码；Firefly 存在多个历史推广链接等。此类信息均原样保留并在报告中显著标红。
5. **待进一步核实 (unverified)**：包括未经验证的所谓“官网域名”、未公开测试的 Claude/Gemini 地区风控表现、无法独立验证的企业背景等。全站所有品牌官网一律标注为「待核实」，坚决不把推广注册跳板链接伪称为官方网址。
6. **运营异常警示 (incident / stale)**：品牌曾出现长时间全节点超时、工单失联、改换主体或仅提供闭源自研客户端锁定等高风险特征，在评测报告中均设立专项避坑章节。

## 三、如何高效使用深度评测做出购买决策

面对 31 家各具特色的代理品牌，盲目追逐单一宣传指标往往容易踩坑。我们建议读者按以下三步法开展核查：

1. **查验客户端是否锁定**：优先确认品牌是否支持标准的 Clash / Shadowrocket / sing-box 通用订阅。如仅支持自研专属客户端（如飞猫云、隐形人），需权衡其上手便利度与多设备迁移成本，详见 [自研客户端机场适合新手吗](/airport/articles/native-app-vs-third-party-beginners)。
2. **核实起步周期与价格口径**：严禁将必须预付全年的折算价格误认为真月付。首次尝试新品牌务必选择 15–25 元档位的月付套餐，实地验证本地宽带晚高峰 20:00–22:30 的连接质量，详见 [20元以内月付机场怎么选](/pricing/articles/under-20-yuan-monthly-guide)。
3. **查阅同类对比与替代矩阵**：在锁定两到三家心仪品牌后，前往 [品牌对比中心](/compare/) 查阅同口径横向对比，或查阅 [品牌替代方案](/brands/alternatives/) 预备次选容灾线路。

## 常见问题

### 品牌深度评测报告与商业详情页有什么区别？

品牌深度评测报告（`/reviews/{slug}/`）聚焦于客观事实、实测截图解读、数据状态分级（实测/商家宣称/历史资料/待核实）、优缺点剖析与多维避坑建议；而商业详情页（`/brands/{slug}/`）主要陈列最新核实的套餐规格、优惠码冲突记录与注册入口，两者的搜索意图与内容结构完全隔离。

### 为什么部分品牌的实测资料中会标注“待核实”或“存在冲突”？

本站遵循严格的数据审计原则，绝不盲信商家宣传文案。例如光速云年付轻量版资料曾同时出现 59GB 与 69GB 两种月流量记录，Firefly 存在多个历史推广链接，云界线与环球梯等品牌存在双优惠码或注册链接格式异常。凡未经第三方二次复核或证据互相矛盾的数据，我们均明确标注为 vendor（商家自述）或 conflicted（存在冲突）。

### 如何利用本目录快速找到最适合自己的机场方案？

建议先通过 [/brands/directory/](/brands/directory/)（31家品牌数据库）按协议、起步月付门槛或客户端类型进行初筛，再点击对应品牌的深度评测报告详细查看晚高峰表现、流媒体/AI 解锁实测记录及真实限制，最后结合 [/compare/](/compare/) 品牌对比中心进行同价位方案横向比较。
